# PROG5121 Part 3

## Message Management

Part 3 implements message management using dynamically populated arrays.

Features include:
- Managing sent, disregarded and stored messages.
- Loading stored messages from the JSON file.
- Displaying the longest stored message.
- Searching messages by message ID.
- Searching messages by recipient.
- Deleting stored messages using their message hash.
- Generating a report of stored messages.

## Testing

Unit tests cover message arrays, message searches, deletion and reports.
